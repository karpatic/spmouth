# Spmouth

- Live site: https://karptic.github.io/spmouth/

This app replicates the simple cut-out mouth effect from “South Park”.

A tiny, just-for-fun webpage made for a friend.
It helps record short videos of a character mouth/face so he can dub over them later.

## How to use

1. If the page asks for **camera** and/or **microphone** permission, allow it (only if you want to record).
2. Record your clip, then save/download it when you’re done.

Tip: For best results, use a modern desktop browser (Chrome/Edge/Firefox) and good lighting.

## Notes

This project was made as a quick, playful tool — not a polished product.
